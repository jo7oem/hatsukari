# サンプルディレクトリ

このディレクトリは、実装前に挙動を確認するためのサンプルコンテンツを配置するルートです。

- 目的: 静的サイト生成の入力例を提供する
- 構成: `content/posts` 配下に Markdown の記事を配置

## ディレクトリ構成

- content/
  - posts/
    - sample-post.md

## 使い方

- `content/posts/sample-post.md` をベースに、記事を追加・編集してください。
- 実装後、ビルド対象を `content/` と切り替えるか、設定で `sample/` を指定して検証します。
