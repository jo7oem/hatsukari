## コンセプト

### 目的
  - CMSとして、個人のブログやメモを簡単に公開できるようにする。
    - 使用フレームワークは最小限とする
      - CSS: Bootstrap
  - ブログは以下のどちらかで記述できる
    - Markdown
    - HTML
  - MarkdownをHTMLに変換して表示する
### 用語定義
- **URL Path**: サイト内での公開パス（例: `/blog/xxx/`）
- **相対パス**: ルートディレクトリからのファイルパス
- **サーバー設定** : ウェブサーバーのとしての設定
- **サイト定義**: サイトの構成やコンテンツの定義
- **コンテンツ定義**: 各ページやファイルの配信設定

### コンテンツタイプ
- **static_dir**: 指定ディレクトリ配下の静的ファイルをそのまま配信
  - 例: 画像、PDF、動画など
  - `.`で始まるファイル/ディレクトリは404
- **static_file**: 指定した静的ファイルのみ配信
  - 配信許可リストで明示
- **static_page**: 静的HTMLファイルを配信
  - 本文ファイル（Markdown/HTML）を指定
  - 追加ファイルも配信可能
- **top_page**: サイトのトップページ（`/`）
  - 基本はstatic_pageと同じ
- **blog**: ブログ記事群
  - 各記事はディレクトリ単位
  - `article.yaml`でメタデータ管理
  - 本文はMarkdown/HTML
  - 改定履歴や追加ファイルも管理

### ディレクトリ構成例
- /
  - トップページ
- /static/
  - 静的ファイル（CSSや共通配信ファイル）
- /blog/
  - ブログ記事一覧
  - 各ブログ記事へのリンク
  - /blog/${page_id}/
    - 各ブログ記事の詳細ページ
    - 記事のタイトル、本文、投稿日、更新日を表示
- /about/
  - 自己紹介ページ

- 任意: 改定履歴、追加ファイル
